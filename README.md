# Nexora AI

**Your AI Workforce. Always On.**

Nexora AI is an AI workforce platform for service businesses. It coordinates specialized agents for sales, reception, follow-up, support, and operations while keeping human approval controls for sensitive actions.

This repository is under active development.

## Initial product goals

- Multi-workspace architecture
- Nexora Manager orchestrator
- Reception, Sales, Follow-Up, Support, and Operations agents
- Lead CRM and conversation history
- Appointment and task workflows
- Human approval queue
- Knowledge base
- Pluggable AI providers
- Connector layer for email, calendar, CRM, and webhooks
- Usage/audit logging
- Local demo mode with no paid AI key required
- Docker and automated tests

See `docs/ARCHITECTURE.md` after the initial build lands.
